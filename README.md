# Zedra | Трекер проектов

Одностраничное клиентское веб-приложение (SPA) для планирования и учёта задач по методологии канбан. Работает полностью в браузере: без серверной части, backend API и базы данных. Все данные хранятся в `localStorage`.

## Требования к окружению

- **Bun** — менеджер пакетов и исполнение скриптов (версия 1.1 и выше)
- Современный браузер: Chrome, Firefox, Edge или Safari (не старше двух последних мажорных версий)

## Установка зависимостей

```bash
bun install
```

## Запуск в режиме разработки

```bash
bun run dev
```

## Сборка и предпросмотр

```bash
bun run build
bun run preview
```

Статическая сборка без сервера:

```bash
bun run generate
```

Результат сборки — каталог `.output/public`, который можно раздать любым статическим сервером.

## Технологический стек

| Технология | Назначение |
| --- | --- |
| Nuxt 4 | основной фреймворк, режим SPA |
| TypeScript | язык разработки |
| shadcn-vue | библиотека UI-компонентов |
| Tailwind CSS | стилизация (в составе shadcn-vue) |
| Lucide Vue | Иконки в приложении |
| Vue composables | хранение состояния приложения |
| localStorage | постоянное хранение данных |
| Vite | сборка (в составе Nuxt 4) |

## Документация

Документация — отдельный сайт на [shadcn-docs-nuxt](https://shadcn-docs-nuxt.vercel.app/) в каталоге `docs-site`. Содержит руководство пользователя, описание архитектуры, руководство разработчика, справочник UI-компонентов и перечень ограничений. Исходные тексты — `docs-site/content`.

```bash
cd docs-site
bun install
bun run dev      
bun run generate
```
