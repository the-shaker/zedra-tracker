## Требования к окружению

- **Bun** — менеджер пакетов и исполнение скриптов (версия 1.1 и выше)
- Современный браузер: Chrome, Firefox, Edge или Safari (не старше двух последних мажорных версий)

## Установка зависимостей

```bash
bun install
```

## Запуск в режиме разработки

```bash
bun run dev
```

Приложение будет доступно на `http://localhost:3000`.

## Сборка и предпросмотр

```bash
bun run build
bun run preview
```

## Статическая сборка

Сборка без сервера:

```bash
bun run generate
```

Результат сборки — каталог `.output/public`, который можно раздать любым статическим сервером.
