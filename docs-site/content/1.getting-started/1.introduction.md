**Zedra | Трекер проектов** — одностраничное клиентское веб-приложение (SPA) для планирования и учёта задач по методологии канбан. Работает полностью в браузере: без серверной части, backend API и базы данных. Все данные хранятся в `localStorage`.

::alert{type="info"}
Регистрация не требуется, данные не передаются на сторонние серверы.
::

## Технологический стек

| Технология | Назначение |
| --- | --- |
| Nuxt 4 | основной фреймворк, режим SPA |
| TypeScript | язык разработки |
| shadcn-vue | библиотека UI-компонентов |
| Tailwind CSS | стилизация (в составе shadcn-vue) |
| Lucide Vue | иконки в приложении |
| Vue composables | хранение состояния приложения |
| localStorage | постоянное хранение данных |
| Vite | сборка (в составе Nuxt 4) |
