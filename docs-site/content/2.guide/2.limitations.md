## Ограничения хранения данных

1. **Данные привязаны к браузеру и устройству.** Хранение реализовано в `localStorage`, поэтому проекты и задачи доступны только в том браузере и профиле, где были созданы. Синхронизация между устройствами и пользователями не предусмотрена.
2. **Очистка данных сайта удаляет всю информацию.** Очистка истории браузера с опцией удаления данных сайтов, а также использование режима инкогнито без сохранения приводят к потере проектов и задач.
3. **Ограничение объёма хранилища.** Размер `localStorage` ограничен браузером (обычно 5–10 МБ). При исчерпании квоты приложение выводит уведомление о переполнении, но новые изменения не сохраняются до освобождения места.
4. **Нет истории изменений.** Отмена действий (undo) и восстановление удалённых проектов или задач не поддерживаются. Удаление подтверждается диалогом и выполняется безвозвратно.
5. **Нет резервного копирования.** Экспорт и импорт данных в файл в текущей версии не реализованы.

## Ограничения многопользовательской работы

6. **Приложение однопользовательское.** Поле «Исполнитель» — это текстовая строка без списка пользователей, аутентификации и разграничения прав доступа.
7. **Одновременная работа в нескольких вкладках.** При открытии приложения в двух вкладках одного браузера изменения не синхронизируются между ними автоматически. Вкладка, сохранившая данные последней, перезаписывает состояние. Рекомендуется работать в одной вкладке.

## Ограничения интерфейса

8. **Минимальная ширина экрана — 768 px.** Вёрстка адаптирована для планшетов и настольных компьютеров. На экранах смартфонов отображение не гарантируется.
9. **Drag-and-drop работает только мышью.** Перемещение карточек реализовано на нативном HTML5 Drag and Drop API, который не поддерживает касания на мобильных устройствах. Для сенсорных экранов используйте перемещение задачи через контекстное меню карточки.
10. **Порядок задач внутри колонки не изменяется перетаскиванием.** Перетаскивание меняет только колонку (статус) задачи. Внутри колонки задачи упорядочиваются выбранным способом сортировки.
11. **Фильтры не сохраняются между сессиями.** Значения поиска, фильтров и сортировки сбрасываются при перезагрузке страницы. Сохраняется только выбор темы оформления.
12. **Фильтры действуют в пределах одного проекта.** Панель фильтрации доступна на доске проекта; глобального поиска по всем проектам нет.

## Особенности логики

13. **Просроченной считается задача с дедлайном раньше текущей даты**, независимо от колонки, в которой она находится. Задача в колонке «Выполнено» с истёкшим сроком также помечается как просроченная.
14. **Удаление колонки переносит её задачи в первую колонку доски.** Задачи не удаляются вместе с колонкой. Удалить последнюю колонку нельзя.
15. **Архивирование проекта не блокирует его задачи.** Архивный проект скрыт из списка активных, его задачи сохраняются, но доска архивного проекта из интерфейса не открывается.
16. **Дата дедлайна не проверяется на прошедшее значение при вводе.** Задачу с прошедшей датой создать можно — она сразу помечается как просроченная.

## Эксплуатационные особенности

17. **Первая загрузка требует подключения к интернету** (или локального сервера) для получения файлов приложения. После загрузки страницы работа продолжается без сети.
18. **Требуются включённые JavaScript и localStorage.** При отключённом JavaScript приложение не запускается, при заблокированном локальном хранилище данные не сохраняются между перезагрузками.
19. **Поддерживаются актуальные версии браузеров** Chrome, Firefox, Edge и Safari — не старше двух последних мажорных версий.
20. **Часовой пояс и формат даты берутся из системных настроек** браузера. Даты отображаются в формате ДД.ММ.ГГГГ.
