## Назначение приложения

«Трекер проектов» — рабочее пространство для планирования и учёта задач по методологии канбан. Приложение подходит фрилансерам, небольшим командам разработки и студенческим проектам, где не требуется многопользовательская синхронизация и облачное хранение данных.

Все данные сохраняются в браузере пользователя и не передаются на сторонние серверы. Регистрация не требуется.

## Начало работы

1. Откройте приложение в браузере.
2. На странице «Проекты» нажмите кнопку **«Добавить проект»**.
3. Введите название проекта (обязательное поле) и, при необходимости, описание.
4. Нажмите **«Создать проект»**.
5. На карточке созданного проекта нажмите **«Открыть доску»**.
6. Нажмите **«Добавить задачу»**, заполните название и статус, сохраните задачу.

Создание проекта и первой задачи занимает не более 15 секунд.

## Работа с проектами

Страница списка проектов содержит карточки проектов с названием, кратким описанием и количеством задач. Проекты разделены на две вкладки: «Активные» и «Архив».

### Создание проекта

Кнопка **«Добавить проект»** открывает модальное окно с полями «Название» и «Описание». Название обязательно и не должно превышать 100 символов, описание — 500 символов.

### Редактирование проекта

Нажмите кнопку с тремя точками в правом верхнем углу карточки проекта и выберите **«Редактировать»**. Откроется то же модальное окно с текущими значениями полей.

### Архивирование проекта

В меню карточки выберите **«Архивировать»**. Проект переместится на вкладку «Архив» и перестанет отображаться среди активных. Задачи проекта сохраняются.

Чтобы вернуть проект, откройте вкладку «Архив» и нажмите **«Восстановить»**.

### Удаление проекта

В меню карточки выберите **«Удалить»**. Приложение запросит подтверждение. После подтверждения проект и все его задачи удаляются безвозвратно.

## Работа с канбан-доской

Доска проекта состоит из колонок-статусов. По умолчанию создаются три колонки: «К выполнению», «В работе», «Выполнено».

В заголовке доски отображаются общее количество задач и количество просроченных задач.

### Создание задачи

Задачу можно создать двумя способами:

- кнопкой **«Добавить задачу»** в заголовке доски — задача попадёт в первую колонку;
- кнопкой **«+»** в заголовке нужной колонки — задача попадёт в эту колонку.

Модальное окно задачи содержит поля:

| Поле | Обязательное | Описание |
| --- | --- | --- |
| Название | да | до 100 символов |
| Описание | нет | до 1000 символов |
| Приоритет | нет | низкий / средний / высокий, по умолчанию средний |
| Статус | да | колонка доски |
| Срок выполнения | нет | дата дедлайна |
| Исполнитель | нет | до 60 символов |

Если обязательное поле не заполнено, сообщение об ошибке выводится непосредственно под этим полем, и задача не сохраняется.

### Карточка задачи

Карточка отображает:

- цветовой индикатор приоритета: синий — низкий, оранжевый — средний, красный — высокий;
- название задачи;
- краткое описание (до двух строк);
- метку приоритета, дату дедлайна и имя исполнителя.

Просроченная задача (дедлайн раньше текущей даты) выделяется красной рамкой, дата подсвечивается красным, и под карточкой появляется подпись «Задача просрочена».

### Перемещение задач

**Перетаскиванием (drag-and-drop):** зажмите карточку левой кнопкой мыши и перенесите её в другую колонку. Колонка под курсором подсвечивается рамкой и фоном. Отпустите кнопку — задача сменит статус.

**Через меню карточки:** нажмите кнопку со стрелкой на карточке и выберите нужную колонку в разделе «Переместить в».

### Редактирование и удаление задачи

В меню карточки доступны пункты **«Редактировать»** и **«Удалить»**. Удаление требует подтверждения.

## Фильтрация, сортировка и поиск

Под заголовком доски расположена панель с четырьмя элементами управления:

- **Поиск по названию** — отображает только задачи, чьё название содержит введённый текст;
- **Приоритет** — все приоритеты / высокий / средний / низкий;
- **Срок** — любой срок / только просроченные / с дедлайном / без дедлайна;
- **Сортировка** — по порядку добавления / по приоритету / по сроку / по названию.

Фильтры действуют одновременно и применяются ко всем колонкам доски. Кнопка **«Сбросить фильтры»** возвращает значения по умолчанию.

## Настройка колонок

Кнопка **«Колонки»** в заголовке доски открывает модальное окно управления статусами. В нём можно:

- переименовать колонку, изменив текст в поле ввода;
- удалить колонку кнопкой с корзиной — задачи из удалённой колонки переносятся в первую колонку доски;
- добавить новую колонку, введя название и нажав **«Добавить»**.

Последнюю колонку удалить нельзя.

## Переключение темы

Кнопка в правом верхнем углу шапки переключает светлую и тёмную тему. Выбор сохраняется между сессиями и восстанавливается при следующем открытии приложения.

## Сохранение данных

Все изменения сохраняются автоматически при каждом действии: создании, редактировании, удалении и перемещении задачи или проекта. Отдельная кнопка «Сохранить» не требуется.

Данные хранятся в локальном хранилище браузера, поэтому:

- при перезагрузке страницы состояние восстанавливается полностью;
- при случайном закрытии вкладки данные не теряются;
- приложение работает без подключения к интернету после первой загрузки страницы.

Если хранилище браузера переполнено или повреждено, приложение выводит уведомление с описанием проблемы.
